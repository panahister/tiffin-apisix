# Visual assets

These repository-owned assets explain the declarative edge boundary without depending on an external
image host.

- `ecosystem-light.svg` and `ecosystem-dark.svg` are the theme-aware README architecture artwork.
- `social-preview.svg` is the editable source for repository and announcement artwork.
- `social-preview.png` is the 1280 × 640 upload-ready GitHub social preview.

Keep the diagram aligned with [`../ARCHITECTURE.md`](../ARCHITECTURE.md). Do not add certificates,
private keys, runtime secrets, or private design identifiers to this directory.
