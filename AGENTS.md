# Repository instructions

- Keep every public document, commit, and pull request in English.
- Never add credentials, tokens, private keys, personal data, production secrets, or machine paths.
- Keep APISIX declarative and preserve backend authorization as the final authority.
- Payments and other internal-only services must not gain public routes without an explicit architecture decision.
- Route changes require source validation plus backend readiness and scenario evidence.
- Do not claim production readiness from a local route or container check.
- Do not commit, push, merge, publish, or add AI attribution without the repository owner's explicit word.
